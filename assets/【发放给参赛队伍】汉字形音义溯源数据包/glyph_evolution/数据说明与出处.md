# 字源数据包 · 数据说明与出处（glyph_evolution）

> 适用赛题：题三「字源 —— 一个汉字的形·音·义溯源」
> 整理：赛题组委会　整理日期：2026-10
> 本目录仅含赛题要求的**字形演变**输入数据；义项、读音、真值数据见包内其余文件。

## 一、目录结构

```
glyph_evolution/
├─ images/<繁体字头>/
│   ├─ 01_甲骨文.svg   商代晚期甲骨文（该字目前未见甲骨著录时缺此帧，见帧清单说明）
│   ├─ 02_金文.svg     商/西周/春秋战国金文（具体分期见帧清单「年代」列）
│   ├─ 03_小篆.svg     秦代小篆（《说文解字》所本一系）
│   ├─ 04_隶书.svg     秦代简牍古隶／西汉马王堆帛书古隶／汉代隶书（具体见帧清单）
│   └─ 05_楷书.png     楷书（公有领域楷书图；无存世古图者以 OFL 开源楷体渲染，逐帧标注）
├─ 字形帧清单.csv      300 行：每帧的字头/阶段/年代/字体名/相对路径/源文件名/来源页/许可/年代核对
├─ 构形解析.csv        60 字：造字法、争议标注、构形解析一句话、《说文解字》依据、数据来源
└─ 数据说明与出处.md   本文件
```

- 共 **60 个字头**（繁体字头建档，CSV 附简体对照），每字实有图像 **4–5 帧**：
  52 字五帧齐全；8 字（漢、湛、環、賜、賞、道、過、城）经核验**目前未见甲骨著录**，
  字形序列自金文起，帧清单中以「甲骨文（未见著录）」行标注核验来源，**不以其他字形顶替**。
- 全部 CSV 为 **UTF-8 带 BOM** 编码。

## 二、字形图像来源与许可

1. **历史字形帧（甲骨/金文/小篆/隶书）**：取自 Wikimedia Commons 的公有领域汉字字形系列
   （许可列逐帧标注为 Public domain）。该系列数字件的源数据主要溯自
   **中央研究院小學堂字形演變資料庫**（https://xiaoxue.iis.sinica.edu.tw/ ）等公有领域整理，
   并参考《说文解字》等传世字书。每帧的 Commons 文件页（含完整来源链接清单）见帧清单
   「来源页URL」列，可逐帧回溯。
2. **隶书帧的年代真实性**：本包隶书帧仅取秦汉材料——秦代简牍古隶、西汉马王堆帛书古隶、
   汉代隶书三类（逐帧见「年代类型核对」列）；**未使用**战国楚系文字或清代复兴隶书冒充汉隶，
   也**未使用**任何现代字库字形冒充古文字。
3. **楷书帧（30 字为开源字体渲染）**：部分字头无存世公有领域楷书图，组委会以
   **Klee One**（Fontworks 公司发布，SIL Open Font License 1.1）渲染为楷书规范字样，
   并在帧清单逐帧标注「开源楷体字样呈现，非古碑帖影像」。楷书属今文字阶段，此举不构成
   以现代字形冒充古文字。OFL 许可证文本见字体发行页：
   https://fonts.google.com/specimen/Klee+One
4. 「甲骨缺佚」核验：经汉字字源网（hanziyuan.net，汉字叔理查德·西尔斯团队，
   2024 年宣布开源、允许商用）逐字核验，上述 8 字甲骨文计数为 0、最早字形为金文，
   帧清单保留核验日期与该站金文编号。

## 三、构形解析的学术口径

- 造字法判断与说解以**許慎《說文解字》**（東漢，公有领域）为基础文献；
  凡据甲骨文、金文材料修正許書者（如「為」「行」），或学界本有分歧者（如「王」「重」「量」），
  一律在「争议标注」列标明 **「一说」** 及分歧所在，不把单一观点当作定论。
- 《说文解字》原文摘句供选手核对；白话释义为组委会据通行文字学著作整理。

## 四、给选手的使用提示

- 图像相对路径以本目录为根（如 `images/人/01_甲骨文.svg`），可直接横向排布做演变序列。
- 展示古文字帧时建议同时呈现帧清单中的「年代」「字体名称」与「来源页URL」。
- 「六书」归属有争议处，赛题鼓励选手并列呈现诸说；真值数据（char_truth.json）
  对争议字采用通行教材口径，已在备注列说明。
